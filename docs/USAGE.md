# 使用指南

[返回项目首页](../README.md)

## 添加服务器

1. 打开「服务器 → 扫码导入」。
2. 手机与电视连接同一局域网，扫描二维码。
3. 填写服务器地址、账号、密码，或上传 AFuseKt 的 `media_server_export.json`。
4. 核对服务器与线路，点击「登录并添加到电视」。

每台服务器可配置多条线路。首页右上角可切换「全部」或单台服务器；各功能参与聚合的范围在「设置 → 服务器与来源」调整。

首页右上角的来源列表里，每台服务器右侧有一个开关（按右键到达）：关掉后它不再参与首页「全部」，电影 / 剧集页也不再列出它，但仍可搜索和播放。同一开关也在「设置 → 数据来源 → 首页与影视来源」。

「设置 → 数据来源」里的每一项都可以单独排序：在某台服务器上按菜单键（或长按确认）拿起，上下移动，再按确认放下。排序决定该功能里各服务器的先后，例如搜索结果的代表副本、详情页其他服务器版本的顺序、在看合并时活动时间相同的取舍、收藏打开哪一份。没排过序的项跟随服务器页的顺序，新加的服务器排在已排序项的末尾；「恢复为服务器顺序」可改回跟随。备份会保存各项的顺序，恢复旧备份时按服务器页顺序。

「影片信息来源」把 TMDB、Bangumi 和各服务器放在同一个列表里：详情页的片名、简介、类型、年份、时长、评分、背景图和 Logo 逐项取列表里第一个开启且有内容的来源。默认 TMDB 在前，然后 Bangumi，然后按服务器页顺序；没有填 TMDB 令牌时 TMDB 不参与。同一作品同时有 TMDB 和 Bangumi 条目（服务器给出了对应 ID）时两边一起参与，例如番剧用 Bangumi 的简介、TMDB 的背景图。演职人员取顺序中第一个有人物名单的来源。电影和剧集的列表卡片（含「在看」的片名）对已经打开过的作品也按这个顺序显示 TMDB / Bangumi 的片名与海报，没有打开过的作品显示服务器自己的。剧集页的单集名、简介和剧照，以及从演职人员进入的人物页（TMDB 人物页或服务器自己的人物页）也按这个顺序决定。

电影 / 剧集页只显示当前服务器实际支持的排序与筛选：服务器忽略的条件（例如只提供 TMDB 列表的服务器）不会出现，年代只列有作品的年代。电影页在服务器有合集时多一个「合集」分段，确认进入合集页查看其中的影片；属于合集的电影，详情页最上方也会像剧集分集一样列出同一合集的其他影片。

## 浏览、选集与播放

| 操作 | 方法 |
| --- | --- |
| 打开导航 | 内容最左侧再按左；首页也可按菜单键 |
| 搜索 | 顶部搜索框，支持中文、拼音与已知首字母候选 |
| 切换片源 | 详情页选择服务器版本，再选音轨与字幕 |
| 快速选集 | 剧集头部的网格图标 |
| 条目菜单 | 卡片上按菜单键，或长按确认后松开 |
| 接着观看 | 首页或「在看」页；有效的本机版本记忆会直接恢复 |

- 在「设置 → 播放 → 默认轨道」分别设置音轨和字幕语言。「源语言」使用作品的原始语言；没有语言资料或对应轨道时跟随服务器。详情页手动选中的轨道优先。字幕选了语言后可打开「特效字幕优先」：同一语言里先选带「特效」徽标的字幕（看轨道标题或外挂字幕文件名，不按 ASS 格式判断），没有时照旧。
- 下集按文件名、版本名和画质特征延续当前版本，并保留音轨、字幕语言。
- 本机版本记忆按电影或单集保存，无法核对旧选项时会回到详情选择。
- 「设置 → 播放 → 版本选择 → 版本偏好」决定默认版本：分辨率、HDR 格式顺序（按确认拿起，上下移动）、IMAX、码率上限与同档码率方向、要避开的视频编码、无损音轨与非原盘。「排序方式」选画质优先或线路优先（默认线路优先，即服务器优先级先于画质）。右侧预览按当前规则排出最近打开的多版本作品，没有时用示例。超过码率上限的版本排到最后，仍可手选。
- 同一页最后的「名称匹配 → 优先匹配」填写正则标记想要的版本，例如 `2160p.*REMUX`；它排在手选之后、其他规则之前，只调整顺序，不隐藏其他版本。
- 进度始终回传实际播放的服务器。可在「设置 → 数据来源 → 观看进度回写」逐台开启跨服回写，默认关闭；播放结束后向已确认匹配的副本写入续播位置或已看状态。不同剪辑版本只写已看，连播下一集与未归类资源不回写；失败不重试，服务器拒绝写入时自动关闭该服务器的回写。此功能已做 mock 验证，尚未在真实服务器与 Zidoo 真机上验证。
- 「取流方式 → 自动」先直连，明确播放错误时尝试本地转发；也可固定直连或转发。

## TMDB 与影视资料

在「设置 → 影视资料 → TMDB 连接」的「令牌」行选择「手机输入」，填写自己的 **API Read Access Token**；也可选「输入」用遥控器在行内输入。API 地址同样支持两种输入，自定义后可「恢复默认地址」。

可分别选择文字、海报与 Logo 语言。未配置令牌时仍能使用 Emby；TMDB 榜单和资料补充需要令牌。Bangumi 与番剧别名功能可单独设置。

从首页 TMDB 进入详情后，即使暂时没有片源也能收藏或加入待看。收藏先存本机，再按作品 ID 同步到已启用收藏同步的服务器。待看保存在本机。手动标记已看也会更新能确认对应关系的服务器副本。

## 弹幕

1. 打开「设置 → 播放 → 弹幕服务器」，在「服务器地址」行选「手机输入」或「输入」，填写自己的弹弹play 兼容 API；地址可保留自建服务的鉴权路径。这一组在弹幕关闭时也显示。
2. 服务要求鉴权时，再填「官方接口」下的 AppId、AppSecret。
3. 在「弹幕」组打开「显示弹幕」，选择显示方式、行数、字号、行间距、上边距与不透明度。字号等按 1920 宽画布的像素设置，组顶部的预览条随设置实时变化；行间距是相邻两行文字之间的距离，任何字号下都不会重叠。滚动、顶部固定和底部固定弹幕按服务返回的类型显示。浮层弹幕跟随显示刷新率逐帧移动整像素，适配 4K 界面和 120 Hz 等高刷新率；这一渲染方式已在模拟器与单元测试中验证，尚未在芝杜真机上完成验收。

| 方式 | 需要设置 |
| --- | --- |
| 浮层 | 开启播放浮层，授予「显示在其他应用上层」权限 |
| 播放器字幕 | 首次在芝杜播放器菜单中打开双字幕，在「字幕2」选中名字带 danmu 的字幕 |

播放器字幕模式会等本集评论下载后生成 `Download/zmby-playback/zmby_danmu.danmu.ass`，与同名播放文件配套，退出播放后清理。主字幕继续按原选择播放。主字幕的外挂数量变化后，可能需要重新选择第二路字幕。

详情页的气泡图标可以搜索和手动选择弹幕。浮窗顶部的「显示弹幕」与设置中的开关相同；弹幕关闭时图标带斜线，仍可从这里重新打开。

- 自动匹配成功后，打开气泡图标可直接查看命中的候选。选择「译名」会切换该作品的默认搜索名并列出分集，也可编辑后用「搜索分集」刷新。
- 剧集默认在本季沿用所选来源和集号偏移；跨季不沿用。
- 缺集或编号有歧义时提示重选，不自动更换手动来源。
- 电影只绑定当前影片；无法确认季身份或分集号时只保存当前集。
- 「本季恢复自动匹配」清除季规则，重新匹配当前集。

需要重新自动匹配时，应用取得同一 TMDB / Bangumi 作品的译名与别名，去重后全部并发查询；当前名称和中文译名优先。服务端的匹配质量和响应速度仍影响结果。

## 片头片尾与下一集

| 功能 | 入口 |
| --- | --- |
| 自动跳过 / 提示按钮 / 关闭 | 设置 → 播放 |
| 查看各来源时间与连接状态 | 详情页 → 片头片尾 |
| 手动设置、修改标记 | 同一片头片尾面板：时间轴显示片头、片尾区间与上次停止位置；时间卡左右键每次 10 秒，长按 1 分钟，未手动设置时从来源的时间开始调整；剧集可存为本集或本季全部，本集没有设置的那一项沿用本季 |
| 下集提示与连播 | 设置 → 播放 |

开启下一集提示后，本集开始准备播放就查找下一集，并预取其弹幕和片头片尾。片段查询由详情、弹窗和播放共用，保存或重试后刷新对应结果。

一个条目有多个版本时，播放按实际播放的版本取服务器标记并核对各来源的时间；时长对不上的标记不使用，改由下一个来源提供。

## 缓存与配置备份

- 「设置 → 缓存」：资料默认 128 MB，图片默认 300 MB；图片上限更改后重启生效。
- 「服务器 → 备份与恢复」：手机导出或上传配置，电视确认后执行。
- 备份含令牌或应用 API 凭据时，需设置至少 8 位密码；忘记密码无法恢复。
- 备份不包含收藏、待看、观看记录、图片缓存或本机季集映射。

## 季集映射

在剧集的季栏打开「季集映射」，或在「未归类」条目中选「映射季集」。可指定单集，也可为某服务器的一个季设置编号范围与集号偏移。保存前可以预览映射结果；映射只在本机生效，不改服务器资料。

## 隐私与反馈

- 登录配置、API 凭据和缓存保存在应用私有目录；服务器令牌目前未额外加密，系统备份已关闭。
- 弹幕服务只收到影视名称、年份、季集号和弹幕 ID，不会收到 Emby 账号、地址或播放链接。
- 手机输入、导入与日志使用局域网 HTTP。仅在可信局域网使用，不要把端口映射到公网。
- 日志会脱敏常见令牌与签名参数，分享前仍需人工检查。不要公开设备备份或原始播放链接。

反馈播放问题时，说明设备、固件、复现步骤，以及问题发生在模拟器还是真实芝杜设备。更多构建与测试方法见[开发指南](DEVELOPMENT.md)。
